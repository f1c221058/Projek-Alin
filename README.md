## 🚀 Fitur Utama

### 1. **Aljabar Matriks Sederhana**
- Operasi dasar: penjumlahan, pengurangan, transpose, perkalian skalar dan matriks.
- Determinan dan invers matriks.
- Implementasi menggunakan Python murni atau `NumPy`.

### 2. **Sistem Persamaan Linear**
- Menyelesaikan sistem persamaan linear menggunakan:
  - Eliminasi Gauss
  - Invers Matriks
  - Fungsi `numpy.linalg.solve`
- Dapat digunakan untuk sistem dengan 2 atau lebih variabel.

### 3. **Principal Component Analysis (PCA)**
- Reduksi dimensi dataset.
- Visualisasi hasil PCA dalam 2D atau 3D.
- Menggunakan `scikit-learn` atau implementasi manual dari eigen decomposition.

---

## 🧠 Konsep yang Dipelajari

- Operasi dasar matriks dan sifat-sifatnya.
- Hubungan antara determinan, invers, dan solusi SPL.
- Konsep vektor eigen dan nilai eigen.
- Penerapan PCA untuk mengurangi dimensi data sambil mempertahankan variansi utama.
